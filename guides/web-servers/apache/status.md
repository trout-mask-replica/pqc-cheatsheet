# PQC status for Apache Web Server

## PQC available?
Yes

## More information
Apache uses OpenSSL for TLS functionality. OpenSSL has supported PQC for both key exchange (ML-KEM) and signing (ML-DSA)since the release of OpenSSL 3.5.
